# Generated CDF graphics folder

in this folder are present all the generated graphics that i have done during my thesis work.

the file are named in this format: **cdf_median_*LINKDIRECTION*_*SNRQUALITY*_*ALGORITHM*.png**

Meanings :
⋅⋅⋅⋅*LINKDIRECTION  uplink or downlink
⋅⋅⋅⋅*SNRQUALITY  good (high snr) bad (low snr)
⋅⋅⋅⋅*ALGORITHM the name of the mac algorithm of the relative test
